# FitFusion 

A modern fitness web application built with React that helps users explore exercises and manage their favorite workouts.

---
Live Demo: https://fit-fusion-khmz.vercel.app

##  Features

-  Search exercises by name, body part, equipment
-  Watch exercise videos (YouTube integration)
-  Add & remove favorite exercises
-  Fully responsive UI
-  Smooth and fast performance

---

##  Tech Stack

- React.js
- Material UI
- RapidAPI (ExerciseDB)
- JavaScript (ES6)
- CSS
